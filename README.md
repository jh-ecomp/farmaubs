# farmaubs
O FarmaUBS é um gerenciador de estoque voltado para a realidade das UBSs de Parnaíba-PI. O FarmaUBS conta com módulos de aceitação e dispensação de medicamentos, ajustes de estoque e conferência mensal, alertas de vencimento e quebra de estoque além do módulo de planejamento de pedido mensal à Central de Abastecimento Farmacêutico de Parnaíba.
